이용약관

이 약관은 B02 Drive Automation이라는 개인용 Google Drive 연결 시험 도구의 현재 공개된 웹 기능에 적용됩니다. 향후 자동화 기능은 실제로 활성화되기 전까지 서비스 범위에 포함되지 않습니다.

현재 웹사이트는 Google Drive 연결 시험 기능만 제공하며, Google OAuth 프로덕션 게시 또는 네이버 블로그 자동 발행 기능을 활성화하지 않았습니다.

1. 서비스의 목적과 범위

본 도구는 사용자가 승인한 Google 계정과 일부 Drive 파일·폴더에 대한 접근 상태를 진단하는 시험용 페이지입니다. 현재 웹페이지의 직접 폴더 생성 버튼은 비활성화돼 있으며, 자동 블로그 발행 기능은 제공하지 않습니다.

2. 이용자의 책임

  • 본인에게 접근 권한이 있는 Google 계정과 파일만 사용해야 합니다.
  • OAuth 승인 전 요청 권한을 확인하고, 접근 동의를 원하지 않으면 중단할 수 있습니다.
  • 파일·폴더 접근 오류가 발생하더라도 조회 결과만으로 원격 데이터가 삭제됐다고 가정하거나, 미확인 생성 작업을 무조건 재시도하지 않아야 합니다.
  • 제3자의 비밀정보나 인증 코드를 공개하거나 서비스 정책을 우회하는 용도로 이용해서는 안 됩니다.

3. 서비스 제공·변경

시험 기능의 제공 상태, 지원 화면, 작동 방식은 안전·호환성·Google API 정책에 따라 변경될 수 있습니다. 테스트 결과만으로 향후 자동화 기능이 항상 작동한다고 보장하지 않습니다.

4. 데이터와 외부 서비스

Google 계정의 권한 부여·철회와 Google Drive의 파일 접근에는 Google 서비스 약관 및 API 정책이 적용됩니다. 정적 웹사이트 호스팅에는 GitHub Pages 관련 정책이 적용됩니다. 본 도구의 데이터 처리는 개인정보처리방침을 확인하세요.

5. 비용 및 연결 상태

현재 공개 시험 페이지에는 유료 요금·구독 결제 기능이 없습니다. 앱 소개 페이지·정책 문서 게시가 Google OAuth 검증이나 장기 인증의 성공을 의미하지 않습니다. 장래 기능을 활성화할 때에는 필요한 승인 및 별도 안내가 선행됩니다.

6. 책임의 범위

현재 도구는 기능 검증을 위한 시험 단계이며, 네트워크 장애·외부 서비스 정책 변경·권한 제한으로 결과가 불완전할 수 있습니다. 관련 법령상 배제할 수 없는 이용자의 권리는 제한하지 않습니다.

7. 문의 및 약관 변경

운영 주체는 GitHub 계정 sonni0205-stack의 개인 프로젝트입니다. 일반 문의는 GitHub 공개 이슈로 접수할 수 있습니다. 개인정보나 Google 계정·인증 관련 비공개 문의는 OAuth 동의 화면에 기재된 사용자 지원 이메일을 사용해 주세요. 주요 변경 시 본 페이지를 갱신합니다.
