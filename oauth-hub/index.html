PERSONAL CREATOR AUTOMATION

콘텐츠 제작부터
보관과 게시까지.

N-SHORTS-AUTO는 소유자가 관리하는 영상 제작 자료를 정리하고, Google Drive에 비공개로 보관하며, 승인된 콘텐츠를 YouTube 채널에 업로드하도록 설계된 개인용 자동화 프로젝트입니다.

프로젝트 알아보기데이터 처리 방식 보기

우리가 하는 일

01 / CREATE

콘텐츠 제작 보조

대본, 음성, 자막, 소스 출처와 편집 기록을 관리합니다. 저작권 확인과 게시 전 검수를 중요하게 다룹니다.

02 / STORE

비공개 파일 보관

Google Drive를 사용해 제작물과 승인 기록을 지정된 사용자 계정의 비공개 폴더에 저장합니다.

03 / PUBLISH

승인 기반 게시

소유자의 Google 계정에서 YouTube 채널을 식별하고, 승인된 영상에 한해 업로드 기능을 사용하도록 설계합니다.

현재 운영 범위

이 사이트는 개인용 도구의 공개 설명 및 정책 페이지입니다. 여기에서 Google 로그인을 받거나 계정 정보를 입력받지 않습니다. 영상 게시 자동화 기능은 별도 환경에서 개발·검증 중이며, 이 페이지 자체가 업로드 서비스는 아닙니다.
