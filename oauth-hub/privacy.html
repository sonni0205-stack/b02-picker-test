개인정보처리방침

시행일: 2026년 10월 26일

N-SHORTS-AUTO(이하 '프로젝트')는 운영자가 자신의 콘텐츠를 제작하고 Google Drive 및 YouTube 계정과 연결하기 위한 개인용 자동화 도구입니다. 본 방침은 프로젝트가 Google API 데이터를 어떻게 접근·사용·보관하는지 설명합니다.

1. 접근하는 정보

  • YouTube: OAuth 동의 시 허용된 범위에서 채널 식별 정보(채널 ID·이름·핸들), 영상 업로드 및 업로드 결과(영상 ID·상태 등)를 이용합니다.
  • Google Drive: 소유자가 허용한 범위에서 제작용 폴더, 콘텐츠 파일과 검수·전달 기록에 접근합니다.
  • 인증 정보: OAuth 토큰 및 클라이언트 설정은 게시·파일 처리에 필요한 인증 목적으로 사용합니다. Google 계정 비밀번호를 요구하거나 보관하지 않습니다.

2. 정보 이용 목적

영상 파일의 비공개 저장·조회, 선택한 채널 확인, 소유자가 승인한 영상 업로드, 중복 게시 방지, 오류 진단 및 최소한의 운영 기록 보존에 사용합니다. 허용된 범위를 벗어난 Google 사용자 데이터 접근은 하지 않습니다.

3. 보관 및 보호

제작 파일과 기록은 운영자가 관리하는 Google Drive의 비공개 폴더 및 제한된 접근 권한의 개발·실행 환경에 저장할 수 있습니다. OAuth 인증 정보는 GitHub Actions Secrets 등 접근이 제한된 비밀 저장 기능에 보관하며 공개 웹페이지·저장소에 게시하지 않습니다. 인증에 필요한 임시 Access Token은 갱신하여 사용할 수 있습니다.

프로젝트 운영에 필요한 동안만 자료를 보유하고, 소유자가 파일·기록·인증 설정을 삭제할 수 있습니다. 개별 서비스의 보관 정책은 각 플랫폼 정책에 따릅니다.

4. 제3자 제공 및 Google 데이터

Google API 데이터는 프로젝트에서 요청한 제작·보관·업로드 기능 수행에만 사용합니다. 관련 Google 서비스와 실행 인프라를 통한 필수 처리 외에 데이터를 판매하거나 광고 목적으로 제공하지 않습니다. 사용자 데이터는 Google API Services User Data Policy의 관련 요구사항과 제한적 사용 원칙에 맞게 처리하도록 설계합니다.

영상이 YouTube에 실제 게시되면 게시 범위 설정에 따라 영상과 설명 등이 YouTube에서 공개되거나 비공개로 보관될 수 있습니다.

5. 동의 철회 및 삭제

연결을 해제하려면 Google 계정의 서드 파티 앱 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 소유자는 자신의 Drive 파일, GitHub Secrets 및 프로젝트 운영 기록을 직접 삭제하거나 교체할 수 있습니다. 이미 공개된 YouTube 동영상은 YouTube Studio에서 별도로 관리해야 합니다.

6. 웹사이트 방문 정보

이 안내 웹페이지 자체에는 계정 로그인 양식, 방문자 추적 스크립트, 광고 픽셀 또는 분석 쿠키를 설치하지 않습니다. GitHub Pages 호스팅에 따른 기술적 접속 기록은 GitHub 자체 정책이 적용될 수 있습니다.

7. 연락 및 변경

문의는 운영자 GitHub 프로젝트 페이지 또는 Google OAuth 동의 화면의 사용자 지원 연락처를 통해 전달할 수 있습니다. 실제 Google 데이터 사용 범위가 변경되면 이 방침을 갱신합니다.

안내
이 정책은 N-SHORTS-AUTO의 현재 개인 운영 범위를 기준으로 작성되었습니다. 향후 별도 공개 서비스로 확장되는 경우 실제 데이터 처리와 담당 연락처를 반영해 수정해야 합니다.
