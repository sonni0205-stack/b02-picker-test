개인정보처리방침

이 문서는 B02 Drive Automation의 현재 브라우저 기반 Google Drive 시험 도구에서 확인한 데이터 처리 방식을 설명합니다. 실제 서비스 운영 방식이 변경되면 시행 전에 수정해야 합니다.

현재 문안은 검토용입니다. 운영자 연락처·도메인 소유권·향후 GitHub Actions 서버 측 OAuth 인증 방식이 확정되기 전에는 정식 제출용 개인정보처리방침으로 간주하지 마세요.

1. 접근하는 정보와 목적

  • Google 계정 이메일: 사용자가 입력한 예상 이메일과 Google Drive about.get의 이메일을 대조하여 계정 오류를 방지합니다.
  • OAuth 웹 클라이언트 ID: 사용자가 승인한 Google OAuth 요청을 시작하는 데 사용합니다.
  • Google Drive 파일·폴더 정보: 사용자가 승인하거나 선택한 범위에서 파일 ID, 이름, 유형, 부모 폴더, 앱 표식과 접근 가능 여부를 조회합니다.
  • 파일 내용: 별도 표준 Picker 시험 화면에서 사용자가 명시적으로 선택한 B02 폴더의 JSON·PNG 파일 내용을 브라우저가 Google Drive API를 통해 읽어 바이트 접근과 해시 계산을 시험할 수 있습니다. 현재 코드상 이 내용을 별도 운영 서버로 업로드하지 않습니다.

2. 요청하는 Google 권한

현재 공개 웹 도구는 https://www.googleapis.com/auth/drive.file 범위만 요청합니다. 이는 앱으로 생성·선택한 항목 등 Google이 허용한 파일 범위의 접근을 위한 권한이며, Google Drive의 모든 콘텐츠가 자동으로 보인다는 뜻이 아닙니다. 읽기 진단은 GET 요청만 사용합니다.

3. 저장 위치와 보유 기간

  • OAuth 액세스 토큰: 브라우저 메모리에 일시적으로 보관됩니다. 읽기 진단은 처리 후 메모리의 토큰 참조를 지우고, 표준 Picker 시험 화면은 사용자가 '지우기'를 누르거나 탭을 닫기 전까지 토큰 참조를 유지할 수 있습니다.
  • 브라우저 localStorage: 사용자 편의를 위해 OAuth 웹 클라이언트 ID와 기존 폴더 ID 등의 비밀이 아닌 설정이 남아 있을 수 있으며, 과거 폴더 생성 상태 미확인 플래그도 저장될 수 있습니다. 이 값은 브라우저 사이트 데이터 삭제 시 지워집니다.
  • 사용자 입력 이메일: 현재 진단 코드에서는 입력값을 브라우저 localStorage에 저장하지 않으며, 대조 작업에 사용합니다.
  • 별도 앱 운영 데이터베이스: 현재 공개 정적 웹페이지 코드는 자체 서버 데이터베이스에 파일 내용이나 토큰을 저장하지 않습니다. Google 및 GitHub의 서비스 자체 로그·저장 내역은 각 제공자의 정책을 따릅니다.

4. 제3자 제공·외부 서비스

사용자 브라우저는 Google의 OAuth·Drive API 및 Picker에 직접 요청을 보내며, 웹사이트 파일은 GitHub Pages에서 제공됩니다. 이 과정에서 Google과 GitHub는 각 서비스 운영에 필요한 정보(예: 인증 정보, 요청 기록, 네트워크 접속 정보)를 처리할 수 있습니다. 현재 공개 클라이언트 코드에는 별도 광고 추적이나 자체 분석 스크립트를 추가하지 않았습니다.

관련 서비스 정책: Google 개인정보처리방침 · GitHub 개인정보 관련 안내

5. 향후 자동화 기능과의 구분

별도의 비공개 GitHub Actions 워크플로와 장기 OAuth 설정은 현재 이 웹페이지에서 활성화된 기능이 아닙니다. 향후 서버 측 갱신 토큰·GitHub Secrets·업로드 등 처리 방식이 실제 사용되기 전에 그 목적, 저장 방법과 보존 정책을 이 문서에 반영하고 별도 승인을 받아야 합니다.

6. 사용자의 선택과 보호 조치

  • OAuth 동의를 거부하거나 Google 계정의 서드파티 연결 관리에서 허용한 연결을 취소할 수 있습니다.
  • 브라우저의 사이트 데이터 삭제로 로컬 설정을 지울 수 있습니다. 단, 이 작업은 Google Drive에 이미 존재하는 파일을 삭제하지 않습니다.
  • 고객 정보, 비밀번호, 토큰, 인증 코드를 이 사이트의 공개 게시물이나 다른 사람에게 공유하지 마세요.

7. 문의 및 개정

데이터 처리 관련 문의는 앱의 Google OAuth 동의 화면에 기재된 사용자 지원 이메일로 접수합니다. 정식 공개 전 운영자의 연락처·응답 방식과 정책 개정 공지 방식을 확인해야 합니다.
